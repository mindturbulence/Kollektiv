# Dashboard fill photo credits

`fill-00.jpg` … `fill-14.jpg` were downloaded once from https://picsum.photos
(seeds `kollektiv-0` … `kollektiv-14`, 600x800) and re-encoded locally as
JPEG quality ~80 to keep file size small. Picsum sources its images from
Unsplash; both are free to reuse under the Unsplash License
(https://unsplash.com/license).

These are bundled locally so the Home montage doesn't make third-party
network requests and still renders offline.
